# Правила работы Claude Code в этом репозитории

## Субагенты

- Поиск по коду, длинные логи и тесты отдавай субагентам **Explore**, **log-reader** и **test-runner** (`.claude/agents/`, модель haiku, только чтение). Дела в 1–3 вызова инструментов делай сам, без субагента.
- Правки, решения и ревью делай сам. Перед правкой проверяй вывод субагента по указанному месту: открой путь:строка и убедись, что там то, что он описал.

## Если не выходит

1. Проверь себя тестами (test-runner или `bun run test`, `bun run check`, `bun run build`).
2. Подними effort на один уровень.
3. Только потом бери модель сильнее.

Перед сменой модели делай `/compact`.
